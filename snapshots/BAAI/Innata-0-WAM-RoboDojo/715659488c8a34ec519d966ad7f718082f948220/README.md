# Innata-0-WAM-RoboDojo

Three-tower world action model for RoboDojo-Sim. This Hugging Face export contains the step 24000 EMA weights for the H5 policy with Joint14 actions.

For inference and evaluation commands, see the [Innata inference repository](https://github.com/baai-eai/innata-framework-inference#release-checkpoint-inference).
