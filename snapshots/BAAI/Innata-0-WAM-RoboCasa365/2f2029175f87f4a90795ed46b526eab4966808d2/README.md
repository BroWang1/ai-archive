# Innata-0-WAM-RoboCasa365

Three-tower world action model for RoboCasa365. This Hugging Face export contains the step 29000 EMA weights for the command-only policy with Control12 actions.

For inference and evaluation commands, see the [Innata inference repository](https://github.com/baai-eai/innata-framework-inference#release-checkpoint-inference).
