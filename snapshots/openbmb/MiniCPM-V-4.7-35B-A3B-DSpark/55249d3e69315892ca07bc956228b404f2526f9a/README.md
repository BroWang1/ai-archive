# MiniCPM-V-4.7-35B-A3B-DSpark

`MiniCPM-V-4.7-35B-A3B-DSpark` is a [DSpark](https://arxiv.org/abs/2607.05147) draft checkpoint trained for exact pairing with [MiniCPM-V-4.7-35B-A3B](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B) and its tokenizer.

The llama.cpp version please see: [MiniCPM-V-4.7-35B-A3B-DSpark-gguf](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B-DSpark-gguf)

## Model Specification


| Property                      | Value                                                                         |
| ----------------------------- | ----------------------------------------------------------------------------- |
| Target model                  | [MiniCPM-V-4.7-35B-A3B](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B) |
| Draft layers                  | 5                                                                             |
| Draft parameters              | 389,223,169                                                                   |
| Draft tokens per forward pass | 15                                                                            |
| Target hidden-state layers    | `[3, 11, 19, 27, 35]`                                                         |
| Checkpoint precision          | BF16                                                                          |


## Training Recipe

Training responses were generated by [MiniCPM-V-4.7-35B-A3B](https://huggingface.co/openbmb/MiniCPM-V-4.7-35B-A3B) from a mixture of Vision & Text prompts.


| Setting            | Value                     |
| ------------------ | ------------------------- |
| Training sequences | 2M                        |
| Epochs             | 6                         |
| Optimizer          | AdamW                     |
| Objective          | CE + L1 + confidence loss |




## Evaluation

Acceptance length is defined as the total number of completion tokens divided by the total number of speculative verification steps. Evaluation uses natural EOS termination and `max_new_tokens=8192`.


| **Domain**            | **Accept Length** | 
| --------------------- | ----------------- |
| **Vision**            |                   |
| MMMU                  | 5.098             |
| MathVista             | 6.126             |
| CharXiv_reasoning_val | 5.479             |
| OCRBench              | 5.407             |
| **Text**              |                   |
| Math                  | 6.687             |
| Code                  | 7.387             |
| General               | 3.501             |




## Usage with vLLM

```bash
vllm serve \
  --model openbmb/MiniCPM-V-4.7-35B-A3B \
  --served-model-name MiniCPM-V-4.7-35B-A3B \
  --tensor-parallel-size 2 \
  --max-model-len 40960 \
  --max-num-batched-tokens 40960 \
  --max-num-seqs 1 \
  --attention-backend FLASH_ATTN \
  --mm-encoder-attn-backend FLASH_ATTN \
  --mm-processor-kwargs '{"downsample_mode":"4x"}' \
  --trust-request-mm-kwargs \
  --disable-custom-all-reduce \
  --compilation-config '{"pass_config":{"fuse_allreduce_rms":false}}' \
  --speculative-config '{"method":"dspark","model":"openbmb/MiniCPM-V-4.7-35B-A3B-DSpark","num_speculative_tokens":15,"enable_adaptive_verification":false}' \
  --default-chat-template-kwargs '{"enable_thinking":false}'
```
