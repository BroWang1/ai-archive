# Ant Ling — Training Content Summaries

This repository provides public training-content summaries for the model versions identified in the documents below. It contains documentation, not model weights or training datasets.

The summaries are organized using the public training-content summary template associated with Article 53(1)(d) of Regulation (EU) 2024/1689. The scope of each document is limited to the model names and versions it identifies. A collection membership, model-family name, quantization suffix, or similar repository name does not extend that scope.

## Reading the summaries

Each summary identifies its own version and update date. It describes training content at the level specified in that document; it does not distribute the underlying training data or grant rights to third-party content. Refer to the relevant model repository for model capabilities, usage instructions, limitations, and license terms.

The existence of these documents is not a certification, an endorsement by an authority, or a statement that every model in the inclusionAI organization or its collections is covered.

## Contact

For questions about these documents, use the contact details in the relevant summary or the provider’s [official contact page](https://developer.ant-ling.com/zh-CN/docs/contact/).
