# FastText language identification model

`lid.176.ftz` is the compressed language identification model published by the
fastText project: https://fasttext.cc/docs/en/language-identification

The model is distributed under the Creative Commons Attribution-ShareAlike 3.0
license: https://creativecommons.org/licenses/by-sa/3.0/

The fastText project states that the model was trained on Wikipedia, Tatoeba,
and SETimes data.
